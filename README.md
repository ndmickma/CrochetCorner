# CrochetCorner! Website

This is my website that I built through the GWC Fall Pathways program. I made a website that talks about me, and my crochet journey and what my buisness is.
I also included photos of some of my projects and a way to order them/contact me!

It is made using HTML and CSS.

# To go to my website: https://ndmickma.github.io/CrochetCorner/

### What I learned
I learned:
-HTML! I learned a whole new coding language and all about the different tags
-CSS! I learned how to style my website using CSS properties.
-How to embed YouTube videos and google forms!
-class and id features in HTML and .class and #id in CSS

### What I struggled with
-It was hard to figure out the embeded link topics
-It was difficult to make the nav bar appear as I wanted to, sometimes it would just randomly misalign.
-At first making the images the size I wanted was hard but then I learned there was a 'width' feature in HTML that I could use for my images.
